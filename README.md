### Andrii Patrikei

Data scientist based in Canada, open to data science roles in Canada. I work on time-series machine
learning: feature extraction, XGBoost and self-organizing maps, dynamic time warping, recurrence analysis
and chaotic dynamics, in R and Python. Previously at VSB – Technical University of Ostrava, Czechia.

**Paper:** Patrikei, Cuberek, Halfar & Martinovič (2026). Essential time series characteristics for
human motion analysis based on Self-Organizing Map clustering. *Acta Gymnica 56*, e2026.004.
[doi:10.5507/ag.2026.004](https://doi.org/10.5507/ag.2026.004): tsfresh, RQA and spectral features,
XGBoost feature selection, SOM clustering of IMU data.

- [movement_classification_v2026](https://github.com/andrii-patrikei/movement_classification_v2026): a robust SOM
  for the paper's pipeline, 8.2 points more accurate on children the model has never seen
  ([interactive report](https://andrii-patrikei.github.io/movement_classification_v2026/))
- [dtwsom](https://github.com/andrii-patrikei/dtwsom): R package, SOMs for variable-length time series with DTW
- [chaos-rcpp](https://github.com/andrii-patrikei/chaos-rcpp): R package, chaotic systems at controlled precision, Lyapunov spectra, RQA, DMD/HAVOK
- [novel_SOM](https://github.com/andrii-patrikei/novel_SOM): 17 SOM variants benchmarked, with a precision ladder from fp32 to 256-bit MPFR

**Tools:** tsfresh · XGBoost · SOM (kohonen, aweSOM) · DTW · RQA · MPFR arbitrary precision · R · Python · Git
